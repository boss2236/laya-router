# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, keep criticism about the code, and don't harass anyone,
in issues, pull requests, discussions or anywhere else this project lives.

## Reporting

If someone's behaviour is a problem, report it privately to the maintainer through
[GitHub's contact options](https://github.com/boss2236) or a
[private security report](https://github.com/boss2236/laya-router/security/advisories/new) if it's urgent.
Reports are kept confidential. The maintainer may remove comments, close threads or block people who
break these rules.
